Website sederhana berbasis Laravel yang dibuat untuk melatih pemahaman dasar tentang konsep MVC (Model-View-Controller), sistem routing, dan penggunaan Blade templating engine. Lewat proyek ini, saya belajar bagaimana menghubungkan URL ke tampilan (Closure) atau Controller, mengolah data dummy menggunakan helper collect, serta mengorganisasi template web agar modular menggunakan layouts, partials, dan components.
Alur kerja website ini mengikuti pola MVC standar. Ketika pengguna mengakses sebuah URL di browser, Laravel memprosesnya terlebih dahulu melalui file routes/web.php. Dari sana, permintaan akan diarahkan ke Controller—seperti MahasiswaController atau DashboardController—yang bertugas menyiapkan logika dan data. Data tersebut kemudian dikirim ke view Blade untuk dirender bersama kerangka layout utama sebelum akhirnya ditampilkan secara utuh di layar pengguna.
Di dalam file rute, aplikasi ini membagi fungsionalitas menjadi beberapa bagian. Halaman Beranda (/), Tentang (/tentang), dan Kontak (/kontak) dibuat sebagai halaman statis yang langsung memanggil view-nya masing-masing. Sementara itu, fitur berbasis data ditangani oleh Controller. Halaman Daftar Mahasiswa (/mahasiswa) mengambil seluruh data mahasiswa untuk ditampilkan dalam tabel lengkap dengan status dan tombol detail. Fitur Detail Mahasiswa (/mahasiswa/{nim}) mencari data spesifik berdasarkan NIM; jika data ditemukan maka akan ditampilkan, namun jika tidak, aplikasi otomatis memicu halaman error 404. Ada juga halaman Profil Mahasiswa (/profil) sebagai contoh tampilan akun, serta Dashboard (/dashboard) yang menghitung dan menampilkan statistik ringkasan status mahasiswa dalam bentuk kartu.
